# Bộ tài liệu tiếng Việt cho Bài 6

Thư mục này chứa 10 tài liệu văn bản nguyên bản phục vụ chương trình lập chỉ mục và truy vấn.

## Quy ước ID tài liệu

ID được xác định theo số ở đầu tên file:

| ID | File | Chủ đề |
|---:|---|---|
| 1 | `01_lap_trinh_python.txt` | Lập trình Python |
| 2 | `02_xu_ly_du_lieu.txt` | Xử lý dữ liệu |
| 3 | `03_tim_kiem_thong_tin.txt` | Tìm kiếm thông tin |
| 4 | `04_tri_tue_nhan_tao.txt` | Trí tuệ nhân tạo |
| 5 | `05_co_so_du_lieu.txt` | Cơ sở dữ liệu |
| 6 | `06_mang_may_tinh.txt` | Mạng máy tính |
| 7 | `07_he_dieu_hanh.txt` | Hệ điều hành |
| 8 | `08_lap_trinh_web.txt` | Lập trình web |
| 9 | `09_an_toan_thong_tin.txt` | An toàn thông tin |
| 10 | `10_hoc_may.txt` | Học máy |

Tất cả file `.txt` được lưu bằng UTF-8. Chương trình Bài 6 nên đọc các file theo thứ tự tăng dần của tên file để ID luôn ổn định.

Các tài liệu được tự biên soạn cho mục đích thực hành, không phụ thuộc vào nguồn văn bản bên ngoài.
